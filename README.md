# 자기 도메인 업무 분해 예시

## 1. 도메인 맥락

산업안전, 산업보건, 환경관리 및 화학물질 위해성평가 분야의 전문지식을 바탕으로 **사업장의 환경안전 법령 준수 업무를 효율화**하고자 한다.

- **문제**: 사업장마다 업종, 규모, 설비, 취급물질 및 작업환경이 달라 적용 법령과 의무사항을 개별적으로 확인해야 한다.
- **자동화 목표**: 사업장별로 적용되는 법령과 의무사항을 AI가 판단하고, 필요한 조치를 안내하는 시스템을 개발한다.

## 2. 네 동작 분석

### ① 분해 (Decomposition)

사업장별 환경안전 법령 준수 판단 업무를 다음 단계로 나눈다.

1. 사업장 기본정보 수집: 업종, 근로자 수, 설비, 취급물질, 작업 내용
2. 관련 환경안전 법령 및 하위 규정 검색
3. 법령별 적용 대상과 조건 확인
4. 사업장 정보와 법령 적용 조건 비교
5. 법정 의무사항과 이행 주기 도출
6. 사업장의 현재 이행 상태 확인
7. 미이행 사항과 필요한 조치 정리

### ② 패턴 인식 (Pattern Recognition)

서로 다른 환경안전 법령에서 반복되는 공통 요소는 다음과 같다.

| 구분 | 공통 요소 |
|---|---|
| 적용 조건 | 업종, 사업장 규모, 설비, 물질, 작업 종류 |
| 의무 유형 | 교육, 검사, 점검, 신고, 기록, 관리 |
| 이행 시점 | 최초, 정기, 변경 시, 수시 |
| 판단 결과 | 적용, 비적용, 추가 확인 필요 |

### ③ 추상화 (Abstraction)

법령마다 다르게 표현되는 요구사항을 공통 데이터 구조로 정리한다.

> 법령명 및 근거 조항 · 시행일 및 적용 조건 · 사업장 관련 정보 · 법정 의무사항 · 이행 주기 및 기한 · 현재 이행 상태 · 필요한 조치 및 증빙자료

단, **법령별 예외조건, 특수한 적용 기준 및 부칙** 등 적용 판단에 중요한 정보는 삭제하지 않고 별도로 관리한다.

### ④ 알고리즘 (Algorithm Design)

1. 사업장의 업종, 규모, 설비, 취급물질 및 작업정보를 입력받는다.
2. 입력된 정보와 관련된 환경안전 법령을 검색한다.
3. 법령의 적용 조건과 사업장 정보를 비교한다.
4. 적용 조건을 충족하는 법령의 의무사항을 추출한다.
5. 사업장의 현재 이행 상태와 법정 의무사항을 비교한다.
6. 미이행 사항과 필요한 조치를 도출한다.
7. 판단 근거가 되는 법령 조항과 시행일을 함께 제시한다.
8. 정보가 부족하거나 법령 해석이 불확실하면 **추가 확인 대상**으로 분류한다.

## 3. 출력 요구

- **형식**: Markdown 표로 작성한 「사업장 환경안전 법령 준수 검토 보고서」
- **언어**: 한국어
- **확장성**: 향후 Excel 및 웹 기반 관리 시스템으로 확장할 수 있도록 데이터 항목을 표준화한다.

| 적용 법령 | 근거 조항 및 시행일 | 적용 사유 | 법정 의무사항 | 이행 주기 | 현재 이행 상태 | 필요한 조치 | 추가 확인 사항 |
|---|---|---|---|---|---|---|---|

## 4. 검증 기준

- **검증자**: 산업안전 또는 환경안전 관리업무 경험이 있는 실무자
- **검증 방법**: 실제 사업장 정보와 해당 시점에 유효한 법령을 비교하여 결과를 검증
- **적합 판정**: 다음 기준을 **모두** 충족할 것
  1. 사업장 특성에 따라 적용 법령과 적용 조건이 정확하게 구분되어 있을 것
  2. 제시된 법령 조항과 의무사항이 실제 법령에 근거할 것
  3. 존재하지 않는 법령이나 근거 없는 의무사항을 생성하지 않을 것
  4. 정보 부족으로 판단할 수 없는 사항은 임의로 단정하지 않고 추가 확인 대상으로 표시할 것
  5. 검증 담당 실무자가 결과물을 법령 준수 업무의 검토자료로 활용할 수 있다고 평가할 것
